# Story of AI

## About the Project

Story of AI is a simple educational website that explains the journey of Artificial Intelligence from its early beginnings to modern-day applications. The website also explores how AI is used in everyday life and what the future of AI might look like.

I built this project to improve my HTML and CSS skills while learning more about Artificial Intelligence.

## Features

* Introduction to Artificial Intelligence
* Brief history of AI
* AI in everyday life
* Future of AI
* AI workflow diagram
* Images, videos, and audio explanations
* Simple and responsive design

## Technologies Used

* HTML5
* CSS3
* GitHub Pages

## What I Learned

Through this project, I learned:

* How to structure web pages using HTML
* How to style websites using CSS
* How to work with images, videos, and audio files
* How to create navigation menus
* How to publish a website using GitHub Pages
* Basic concepts of Artificial Intelligence
